# OsintGram Desktop

Неофициальный Telegram-клиент для Windows с инструментами OSINT — для журналистов, фактчекеров и тех, кто разбирает скам.
Основан на [Forkgram Desktop](https://github.com/Forkgram/tdesktop), который основан на [Telegram Desktop](https://github.com/telegramdesktop/tdesktop).

> OsintGram не связан с Telegram FZ-LLC. Данные обрабатываются локально, приложение общается только с серверами Telegram.
> Версия для Android: [OsintGram](https://github.com/doksek/OsintGram).

## Функции OSINT

Правый клик по любому сообщению:

**OSINT: отчёт по сообщению** — ID и ссылка на сообщение, точное время в UTC и время редактирования, просмотры, подпись автора; «паспорт» отправителя (ID, все юзернеймы, тип, метки verified / premium / **SCAM** / **FAKE**); откуда переслано — исходный канал, ID и ссылка на оригинал, дата оригинала; медиа (имя файла, MIME, размер, ID); индикаторы в тексте — ссылки (включая скрытые), @упоминания, e-mail, кошельки BTC / ETH (EVM) / TRON / TON; SHA-256 текста.
Кнопка **Сохранить доказательство** — `.json` + `.txt` с временем фиксации и SHA-256 в `Загрузки/OsintGram/evidence`.

**OSINT: анализ чата** — по загруженным сообщениям:
- активность по часам и дням недели (UTC) — помогает понять часовой пояс автора;
- средние и максимальные просмотры, отношение просмотров к подписчикам (признак накрутки);
- источники пересылок — из каких каналов и сколько раз репостили;
- **Индикаторы в CSV** — все ссылки, упоминания, e-mail и кошельки с количеством и первым появлением;
- **Архив с хешами** — HTML + JSON всех загруженных сообщений и файл с SHA-256 (`Загрузки/OsintGram/archives`).

**OSINT: заметки к чату** — удобное поле для заметок по каждому чату, сохраняется в `Загрузки/OsintGram/notes` в формате Markdown.

**OSINT: искать во всех чатах** — ссылки, @упоминания и кошельки из сообщения одним кликом ищутся по всем вашим чатам и каналам.

**OSINT: поиск по фото** (для сообщений с фото):
- обратный поиск в Яндекс Картинках, Google, Bing и TinEye — фото копируется в буфер, остаётся нажать Ctrl+V на открывшейся странице;
- **Где ещё было это фото** — находит то же фото в других чатах, даже пережатое или слегка обрезанное (перцептивный хеш). Индекс пополняется кнопкой «Индексировать фото» в анализе чата.

**OSINT: мониторинг слов** — список слов, фраз, кошельков или ссылок; когда они появляются в новом сообщении любого вашего чата или канала, приходит уведомление, а находка записывается в `Загрузки/OsintGram/monitor/hits.csv`.

Чтобы проанализировать больше истории, прокрутите чат вверх — анализ работает по тому, что загружено.

Чего OsintGram намеренно **не делает**: скрытое отслеживание онлайна конкретных людей, поиск по утёкшим базам, массовый сбор телефонов.

## Установка

1. Откройте [Releases](../../releases/latest) и скачайте `OsintGram-Desktop-Windows-x64.zip`.
2. Распакуйте и запустите `OsintGram.exe`.

OsintGram хранит данные отдельно от Telegram Desktop и Forkgram, их можно запускать одновременно.

## Сборка

Сборка идёт в GitHub Actions (`.github/workflows/osintgram_win.yml`):
1. Форкните репозиторий.
2. Получите `api_id` и `api_hash` на [my.telegram.org](https://my.telegram.org).
3. Добавьте секреты `APP_ID` и `APP_HASH` в **Settings → Secrets and variables → Actions**.
4. **Actions → OsintGram Windows → Run workflow**. Первая сборка долгая (собираются библиотеки), следующие быстрее за счёт кеша.

Код OSINT-функций: [`Telegram/SourceFiles/menu/menu_osint.cpp`](Telegram/SourceFiles/menu/menu_osint.cpp).
